A light week, 14 messages across three topics. Most of the activity sat in the Yaroslav chat thread around an optimizer idea.

Yaroslav shared that he and a collaborator brainstormed an optimizer update meant to be efficient specifically for self-attention, rather than staying generic like Adam, with the working notes in a Google Doc: <https://docs.google.com/document/d/1wPh17-tHLOunoiOkb-cND4XE2v5-F0KePkXsTtbeD-I/edit?tab=t.0>. He framed the underlying question as how much room for improvement exists when using structure-specific solvers instead of gradient descent, noting that different data regimes (random versus realistic) should give different answers but correlate. He also pointed to related outside work on curvature along gradient directions and a different-optimizer-per-layer idea: <https://9dlabs.xyz/writing/curvature-along-gradient-directions>.

Gabriel asked why generate new data instead of picking a small, easy dataset and fixing the architecture to single-layer attention. Yaroslav agreed that works too, but said starting from the simplest possible setting (something like one example, two features, three layers) makes correctness easier to check. Gabriel said that small, easy dataset was what he had in mind for the same reason.

Armins gave the practical constraint: the biggest bottleneck right now is finding a toy problem where optimizing attention correlates with optimizing attention inside an actual LLM training setting. If that can be shown, he is happy to switch task setting.

In the wikitext thread, the discussion was about cross-entropy versus accuracy. Gabriel observed that CE differs significantly between modded-nanoGPT and the count-based methods even when accuracy looks similar. Yaroslav noted gradient descent minimizes cross-entropy directly, so a lower value there is expected, and that an ngram method could move CE without changing accuracy via a non-linear transform on the probabilities. Armins suggested the test for adding a CE track is whether it leads to interesting methods, and asked what happens when an autoresearch optimizer is run to maximize CE. Gabriel added that keeping CE as a separate threshold track could help rule out brittle methods.

No decisions were recorded this week. The open question carried forward is the toy problem one: find a setting where attention optimization correlates with LLM training before committing to it.
