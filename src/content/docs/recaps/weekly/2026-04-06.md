A working week split across the two main chats, 60 messages total. Most of the energy went to ByteDMD escape-hatch hardening and a NoProp experiment that came back negative.

## What moved

On ByteDMD, Yaroslav pointed Sung Jae at the strictest implementation, `bytedmd_settrace`, used the same way as `bytedmd` but imported from the strict module ([settrace source](https://github.com/cybertronai/ByteDMD/blob/main/bytedmd_settrace.py), [usage](https://github.com/cybertronai/ByteDMD/blob/main/README.md#usage)). Seth reviewed Sung Jae's [PR #4](https://github.com/cybertronai/ByteDMD/pull/4#issuecomment-4210473150) and floated requiring Python 3.13+ to sidestep the 3.12 `f_trace_opcodes` bug that causes a known test failure. Sung Jae noticed the strict tracker had gone missing, then opened [PR #5](https://github.com/cybertronai/ByteDMD/pull/5) to bring back the strict testing file, fix the escape, and add a benchmark run showing it. Yaroslav also shared a [strict variant on dev](https://github.com/cybertronai/ByteDMD/blob/dev/bytedmd_strict.py).

Seth opened [PR #78 on SutroYaro](https://github.com/cybertronai/SutroYaro/pull/78) with a NoProp experiment, diffusion-style local learning with no inter-layer backprop. The result was negative: NoProp solves parity but does not beat SGD plus Curriculum on convergence or DMD.

Yaroslav is still on Sparse Parity and reported finding bugs in the metric, noting he needs a liveness analysis so it does not behave like a program with a memory leak, and that he had spoken with the author of the data movement distance paper. Silen Naihin's auto researcher came up, with Yaroslav asking how many GPUs it needs ([autoresearch-distillation](https://github.com/SilenNaihin/autoresearch-distillation)); Silen was running an 8b model and gathering baselines ([sparse_parity](https://github.com/SilenNaihin/autoresearch-distillation/tree/main/sparse_parity)).

On tooling, Yad recommended trying Anthropic's agent teams before Ralph for a Claude Code loop ([agent teams docs](https://code.claude.com/docs/en/agent-teams), [ralph-wiggum plugin](https://github.com/anthropics/claude-code/tree/main/plugins/ralph-wiggum)). Yad also flagged a blocked setup: a lockout where Terminus lacks the authorization level to spawn processes over SSH, with access expected back Friday. Andy started a convention separating an agent prompt from an agent task and put it in a new PR ([PR #73](https://github.com/cybertronai/SutroYaro/pull/73)), wanting to learn about Muon.
